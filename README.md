# Java Testing

This repository is dedicated to my studies of software testing for the Software Engineering 2 course at my university.

The topic is explored using Java and its testing frameworks, such as JUnit and Mockito.

## Structure

Each topic has its own folder:

- `JUnit/` – unit testing with JUnit
- `Mockito/` – mocking dependencies with Mockito
- `WhiteBox/` – white-box testing: control flow graphs, line and branch coverage
- `Mutation/` – mutation testing

Inside each topic, every exercise lives in its own package:

- `src/main/java` – the classes under test
- `src/test/java` – the corresponding tests
